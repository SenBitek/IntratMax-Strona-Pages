# 🌐 PUBLICZNE — Intrat-Max: pliki publikacyjne

To repozytorium zawiera wyłącznie gotową wersję strony obsługiwaną przez
GitHub Pages.

## Nie edytuj tego repozytorium ręcznie

Źródła strony znajdują się w prywatnym repozytorium
[`SenBitek/IntratMax-Strona`](https://github.com/SenBitek/IntratMax-Strona).
Wszystkie przyszłe zmiany należy wykonywać właśnie tam.

- **Prywatne repozytorium:** kod źródłowy, zdjęcia i testy.
- **To publiczne repozytorium:** wynik kompilacji potrzebny do działania strony.

Strona produkcyjna: [https://intrat-max.pl](https://intrat-max.pl)

Repozytorium nie zawiera kluczy API ani innych sekretów.
